# Eom-Lyrics

유튜브 뮤직에서 재생 중인 곡의 가사를 앨범 커버 위에 보여주는 Android 앱입니다. 싱크 가사는 현재 줄을 강조하고, 지원되는 외국어 가사는 한국어 번역을 함께 표시할 수 있습니다.

## 다운로드

**[테스트 APK 다운로드](https://github.com/umtej2/Eom-Lyrics/releases/download/v0.1.0-test/FloatingLyrics-test.apk)** · Android 10 이상 · 약 30MB

## 설치와 사용

1. Android 휴대폰에서 APK를 다운로드하고 열어 설치합니다. 설치가 막히면 휴대폰 안내에 따라 파일을 연 앱의 **출처를 알 수 없는 앱 설치**를 허용합니다.
2. 설치한 **Floating Lyrics**를 열고 **알림 접근 설정 열기**에서 앱의 알림 접근을 허용합니다. 이 권한으로 현재 곡과 재생 위치를 읽습니다.
3. **가사창 접근성 설정 열기 → 설치된 앱 → Floating Lyrics 가사창**에서 서비스를 켭니다. 이 권한으로 유튜브 뮤직의 재생 화면을 감지하고 가사창을 표시합니다.
4. 유튜브 뮤직에서 곡을 틀고 **지금 재생 중** 화면의 **앨범 커버**를 누릅니다. 커버 위에 가사가 열리고, 다시 누르면 닫힙니다.

가사창 오른쪽 위의 **새로고침** 아이콘으로 다시 검색할 수 있습니다. 오른쪽 아래의 **팝업** 아이콘을 누르면 작은 가사창으로 바뀝니다. 팝업은 끌어서 옮기고 짧게 눌러 닫을 수 있습니다. 글자 크기, 표시 줄 수, 한국어 번역은 Floating Lyrics 앱에서 설정할 수 있습니다.

### 접근성 설정이 막힐 때

Android에 **제한된 설정** 안내가 나오면 **설정 → 애플리케이션 → Floating Lyrics → ⋮ → 제한된 설정 허용**을 선택하고 접근성 설정으로 돌아갑니다. 메뉴 이름은 기기에 따라 다를 수 있습니다. [Android 도움말](https://support.google.com/android/answer/12623953?hl=ko)

테스트 버전입니다. 곡에 따라 가사나 싱크 정보가 없을 수 있으며, 새 가사 검색과 온라인 번역에는 인터넷 연결이 필요합니다.
