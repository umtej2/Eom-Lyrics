# Eom-Lyrics

YouTube Music에서 재생 중인 곡의 가사를 보여주는 Android 앱입니다. 시간 정보가 있는 가사는 현재 줄을 강조하고, 가사 줄을 눌러 해당 구간으로 이동할 수 있습니다.

## 설치와 사용

1. APK를 휴대폰에서 열어 설치합니다. 필요하면 파일을 연 앱의 **출처를 알 수 없는 앱 설치**를 허용합니다. 같은 서명으로 설치된 이전 버전은 업데이트할 수 있습니다.
2. 앱의 **홈 → 시작 준비**에서 **알림 접근**과 **가사창 접근성**을 허용합니다. 접근성 설정에서는 **설치된 앱 → Floating Lyrics 가사창 → 사용**을 켭니다.
3. **설정 → 가사창과 조작 → 가사창 사용**을 켜고, 여는 방식을 **앨범 커버 / 가사 버튼** 중 선택합니다.
4. YouTube Music의 **지금 재생 중** 화면을 엽니다. 앨범 커버 방식은 **설정한 가사창 영역**을, 버튼 방식은 우하단 **가사 아이콘**을 누릅니다. 닫기는 우하단 **× 아이콘**을 사용합니다.
5. **설정 → 가사창 위치**에서 가로·세로 위치를 맞춥니다. 위치는 저장되며, 앨범 이미지나 곡 제목 좌표에 따라 자동으로 바뀌지 않습니다.

### 가사창 조작

- **가사 줄 터치:** 시간 정보와 재생 위치 이동을 지원하는 곡에서 해당 구간으로 이동합니다. 드래그하면 스크롤합니다.
- **재생목록:** 목록이 펼쳐진 것으로 인식되면 가사창의 **위쪽 절반**을 사용합니다. 터치 영역과 버튼도 함께 이동하고, 목록을 내리면 원래 높이로 돌아옵니다.
- **작은 팝업:** 닫기 아이콘 위의 팝업 아이콘을 누릅니다. 팝업은 끌어서 옮길 수 있고, 짧게 누르면 커버 가사창으로 복귀합니다. 다른 앱에서도 가사를 볼 수 있습니다.
- **설정:** 글자 크기, 배경 어둡기, 현재 가사 따라가기, 구간 이동, 한국어 번역, 팝업 표시 줄 수와 위치를 조절합니다.

### 접근성 설정이 막힐 때

**설정 → 애플리케이션 → Floating Lyrics → ⋮ → 제한된 설정 허용**을 선택한 뒤 접근성 설정으로 돌아갑니다. 기기에 따라 메뉴 이름이 다를 수 있습니다. [Android 도움말](https://support.google.com/android/answer/12623953?hl=ko)

## 패치 노트

### v0.2.0-test · 2026-11-06

- **앱 화면 개편:** 어두운 배경의 홈·설정·앱 정보 화면을 추가하고, 설정을 기능별로 정리했습니다.
- **가사창 버튼 정리:** 새로고침을 제거하고 가사 열기·닫기를 아이콘으로 변경했습니다. 팝업 아이콘은 그 위에 배치했습니다.
- **고정 위치:** 앨범·제목 좌표에 의존하던 위치 계산과 전환 애니메이션을 제거했습니다. 저장된 위치 조정값을 계속 사용합니다.
- **재생목록 모드:** 목록이 보이면 높이를 절반으로 줄여 위쪽만 남기고, 터치 영역과 버튼도 맞춥니다. 전환 시 가사 켜짐 상태와 배경 어둡기를 유지합니다.
- **표시 화면 제한:** 일반 가사창과 버튼은 전체 재생화면에만 표시하도록 조건을 강화했습니다. 직접 연 작은 팝업은 별도로 동작합니다.
- **가사 구간 이동:** 가사 줄 터치로 재생 위치를 이동하고, 드래그는 스크롤로 구분합니다.
- **곡 검색 개선:** 피처링·기호·띄어쓰기·일부 다국어 별칭을 처리하고, 제목·아티스트·재생 길이와 곡 버전을 비교합니다.
- **작업량 줄이기:** 재생 상태 변경 알림과 다음 가사 시점의 갱신을 사용하고, 연결 수·캐시 크기를 제한했습니다. 실제 배터리·메모리 절감량은 측정하지 않았습니다.

## 참고

가사 출처는 LRCLIB·벅스·지니·LyricRadar·YouTube Music입니다. 곡과 출처에 따라 가사나 시간 정보가 없을 수 있습니다. 새 가사 검색과 온라인 번역에는 인터넷 연결이 필요하며, 현재 번역 서비스의 제한 때문에 번역이 실패하거나 품질이 고르지 않을 수 있습니다.

테스트 버전입니다. 기기와 YouTube Music 버전에 따라 전체 재생화면·재생목록 인식이 달라질 수 있습니다. Android 앱의 화면과 가사 조회 방식은 친구의 Floating Lyrics 확장 프로그램을 참고했습니다.
